# Banking Customer, Transaction & Loan Analytics

## Project Overview

This project analyzes banking customer, account, transaction,
loan, card and order data using MySQL and Power BI.

The project focuses on understanding customer behavior,
transaction patterns, account activity and loan performance.

## Tools Used

- MySQL
- SQL
- Power BI
- DAX
- Excel/CSV
